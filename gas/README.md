# WK画像リレー(Google Apps Script)

iOSの共有シート → ショートカット から送った画像を、fusion_portal のウェルカム画面が
自動的に取り込めるようにするための中継サーバー。fusion_portal 自体はバックエンドを
持たない静的SPA(GitHub Pages)なので、この中継だけ別に Google Apps Script(GAS)で
用意する。

```
iOS共有シート → ショートカット → (POST) → GAS Web App → Driveの専用フォルダに一時保存
                                                              ↓ (GET, 取得後にDriveから削除)
                                        fusion_portal ウェルカム画面が定期的/起動時に取り込む
```

## 1. Apps Scriptプロジェクトの作成

1. https://script.google.com/ で「新しいプロジェクト」を作成する。
2. デフォルトの `Code.gs` の中身を、このリポジトリの `gas/WkImageRelay.gs` の内容で置き換える。

## 2. 共有シークレットの設定

コードにシークレットを直接書かないため、スクリプト プロパティに設定する。

1. 左メニューの「プロジェクトの設定」(歯車アイコン) を開く。
2. 「スクリプト プロパティ」→「スクリプト プロパティを追加」。
3. プロパティ名: `WK_IMAGE_SECRET`、値: 任意のランダムな文字列(推測されにくい長さのものを推奨)。

この値は、後述のiOSショートカットと fusion_portal の設定画面(設定 → WK画像 (GAS連携))の
両方に同じものを入力する。

## 3. Webアプリとしてデプロイ

1. 右上の「デプロイ」→「新しいデプロイ」。
2. 種類の選択で「ウェブアプリ」を選ぶ。
3. 「次のユーザーとして実行」: 自分。
4. 「アクセスできるユーザー」: 全員。
   - この設定により、URLと共有シークレットさえ知っていれば誰でも呼び出せるようになる。
     URLとシークレットは第三者に教えないこと。個人利用を想定した簡易的な認証方式である。
5. デプロイ後に表示される「ウェブアプリのURL」(`https://script.google.com/macros/s/.../exec`)
   を控えておく。これを fusion_portal の設定画面に入力する。

コードを更新した場合は、同じデプロイを「編集」→ バージョンを「新バージョン」にして
再デプロイしないと反映されない点に注意する。

## 4. iOSショートカットの作成

「ショートカット」アプリで新規ショートカットを作成し、以下のアクションを追加する。

1. **共有シートで受け取る**: ショートカットの詳細設定で「共有シートに表示」をオンにし、
   受け付ける種類を「画像」にする。
2. **イメージを変換**: 受け取った画像をJPEGに変換(元がHEIC等の場合の互換性のため)。
3. **Base64にエンコード**: 「エンコード」アクションで、変換した画像をBase64エンコードする。
4. **辞書を作成**: 以下のキーを持つ辞書を作る。
   - `secret`: 手順2で設定した共有シークレット(固定のテキスト)
   - `dataBase64`: 手順3のBase64エンコード結果
   - `mimeType`: `image/jpeg`(固定のテキスト)
   - `filename`: 任意(空でも可)
   - `targetPath`: 省略可。省略した場合、fusion_portal側では「次に開いた
     機能ページへ自動的に反映される」画像として扱われる(通常はこれでよい)。
     特定の機能ページ専用のショートカットにしたい場合だけ、例えば `/generator`
     や `/banzai-pose` を指定する。
5. **URLの内容を取得**: 手順3で控えたWebアプリのURLへ、
   - メソッド: POST
   - 本文の種類: JSON
   - 本文: 手順4の辞書
   でリクエストを送る。

これで、写真アプリの共有ボタン → このショートカットを選択、で画像がGAS経由で
fusion_portalへ送られるようになる。fusion_portal側は、アプリが表示された瞬間
(起動時・前面に戻ってきた時)に1回取り込みを試みるほか、ウェルカム画面の
「🔄 GASから取り込む」ボタン、設定画面の「🔄 今すぐ取り込む」ボタンからも
即座に取り込める。アプリを開きっぱなしのまま共有するケースにも対応したい場合は、
設定画面で自動ポーリングをオンにする(既定はオフ)。

## 制約・注意点

- 認証は共有シークレットのみの簡易的なもの。URLとシークレットの両方を知っている
  第三者は誰でも画像を読み書きできてしまうため、個人利用の範囲にとどめること。
- 画像はGoogleのサーバー(Drive)を一時的に経由する。機密性の高い画像を扱う用途には
  向かない。
- fusion_portalが取得(GET)した画像は、その時点でDriveから削除される
  (同じ画像の二重取り込みを防ぐため)。取り込み前にDrive上のファイルを直接
  削除・移動しないこと。
